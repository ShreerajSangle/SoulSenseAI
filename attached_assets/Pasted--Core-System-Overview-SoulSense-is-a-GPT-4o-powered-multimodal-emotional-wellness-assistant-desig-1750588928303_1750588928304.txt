🧠 Core System Overview
SoulSense is a GPT-4o-powered multimodal emotional wellness assistant, designed to deliver empathetic, human-like conversations through four distinct AI personas — Dr. Sarah (clinical therapist), Alex (supportive friend), Marcus (motivational coach), and Maya (mindfulness guide). The system uses emotion-aware response conditioning, dynamic mood detection, and long-term memory integration to simulate therapeutic, friendly, and personalized dialogues — similar to Replika, but smarter and cleaner.

💬 Conversational Engine (GPT-4o with Emotional Conditioning)
Replace any existing LLMs or fallback modules with OpenAI's GPT-4o, which allows fast, stream-based token replies with emotionally rich responses. No “Advanced AI” toggle should exist — GPT-4o should power every chat session automatically per persona selection.

Each persona's prompt must include personality conditioning and emotional injection. For example, when emotion is detected as “anxious” and persona is Marcus:
"User feels anxious. You are Marcus, a motivational coach. Uplift their spirit with energetic tone and short affirmations."

All chats must support streaming replies, emotion-based emoji additions, typing indicators, and must avoid repetition by combining history + emotional tone + GPT few-shot priming.

Each persona’s tone should reflect its identity:

Dr. Sarah → Calm, CBT-based advice and therapy tone

Alex → Casual, friendly, humorous

Marcus → High-energy, empowering, direct

Maya → Spiritual, soothing, mindfulness-oriented

😄 Emotion Detection Pipeline
Integrate the GoEmotions BERT Classifier to process each user input and return a primary emotion (e.g., sadness, anxiety, joy) + intensity score.

Use this output to condition GPT-4o prompts dynamically in real-time, giving the chat true emotional intelligence.

Optional: Save emotion trend data to the database and use it to build mood tracking visuals across days or sessions.

🧾 User Interface (Clean, Modern, Intuitive)
The app must launch directly to the Home UI, which includes mood check-in, persona selection, and a dashboard preview.

Remove all old tabs and clutter like Chat, History, Journal, and Profile from the main navigation bar. Instead, move features like Journal and Session History into popups or sidebar panels that match the main homepage style.

All dropdowns or translucent UI components (e.g., diary entry forms, chat feedback inputs) must be replaced by popup modals that are fully visible, responsive, and styled with rounded corners, gradient overlays, and theme-matching colors.

Every chat bubble should reflect the selected persona's identity, using custom emoji packs (e.g., Maya 🌸, Alex 😄, Marcus 💪), tone-specific fonts/colors, and user-friendly spacing.

🧠 Memory + Personalization (Supabase with Realtime Sync)
Store all user information — including profile data (name, age, avatar, goals, preferred persona), diary entries, mood logs, and session chat logs in Supabase (PostgreSQL).

Use Supabase Realtime or Firebase to sync changes live without reloading pages.

All update actions (e.g., saving profile, editing journal, new diary entries) should trigger real-time database updates and render changes back into UI immediately.

Fix all current bugs where forms don’t update or data doesn’t reflect after submission. Forms must validate inputs, save correctly, and show confirmation animations/messages.

📓 Journaling & Diaries (Popup-Based)
Replace the current broken or translucent diary/journal UI with a clean popup modal system.

New entries, edits, and reviews must all appear in well-designed modals with title, date, emotion tags, and save button.

Allow emotion tagging from detected input or user selection for each journal entry.

Use Supabase to store all diary entries with timestamps, and retrieve on demand in a searchable timeline-style UI.

🎨 Dark Mode & Theme Enhancements
Dark mode toggle must apply globally across the entire app — not just Profile Settings.

Fix the bug where dark mode turns off immediately after toggling on.

Redesign dark mode to use calming dark gradients, soft shadows, and persona-specific accent colors to retain visual richness and readability.

Include mood-adaptive background themes, where background images/colors adjust based on user's emotional state or selected persona.

🗃️ Session History Panel
Redesign Session History to be part of the home/dashboard UI, not a separate tab.

Remove current layout and build a clean, scrollable timeline that shows date, active persona, detected mood, and key conversation highlight.

Enable session export (PDF or text) and quick summary view like YouperAI.

Store all sessions in Supabase with rich metadata: mood, keywords, emotion trends, selected persona.
