To elevate the intelligence, emotional awareness, and user experience of the SoulSense AI assistant, a series of integrated upgrades are being implemented across memory, persona depth, conversation flow, quality control, and dynamic backend logic. The first enhancement involves building a robust Memory System, combining both short-term and long-term memory. Short-term memory will track session-specific context such as the user’s current mood, tone, goals, and key conversation history, while long-term memory will retain persistent user traits including their name, past emotional patterns, and preferred coping styles. This will be powered by vector-based retrieval using tools like FAISS or ChromaDB, allowing the assistant to reference prior conversations in a context-aware manner—e.g., Maya recalling the user enjoys poetry during emotionally heavy moments.

Next, we’re implementing Upgraded Persona Prompts for all four personas—Dr. Sarah, Maya, Marcus, and Alex. Each prompt will define the persona's background, therapeutic tone, and domain-specific techniques. Dr. Sarah will use CBT-inspired questioning and mental health logic; Maya will speak in poetic metaphors and offer mindfulness-based affirmations; Marcus will provide practical, structured guidance with motivational focus; and Alex will inject humor, meme-style phrasing, and casual relatability. These prompts will be tailored with emotional tuning, ensuring each persona responds appropriately based on the user’s detected emotion (e.g., a nurturing tone when sadness is detected).

To streamline dialogue structure and reduce repetition or aimless responses, a Conversation Flow Engine is being developed using a finite state machine (FSM) or intent-entity model. This engine will control the progression of conversations across soft stages such as: emotional check-in, exploratory dialogue, emotional reflection or guidance, solution framing, and closure. The assistant will know what phase it's in and what type of question or message is appropriate, leading to smoother, more emotionally aligned conversations.

Complementing this, a Conversation Quality Evaluator module is being built to score each generated response using lightweight, rule-based heuristics or shallow models. The evaluator will rate replies on metrics like empathy level, relevance, persona consistency, and emotional appropriateness. Low-scoring responses can be flagged for refinement or retried automatically, helping the system learn and improve conversational quality over time.

Finally, all of these upgrades will be tied together through dynamic prompt integration in the controller.py backend, ensuring the right system prompt is injected based on the active persona, user’s current emotion, conversation phase, and memory state. This prompt engine will pull the correct persona prompt, attach memory context, emotion labels, and any other necessary dynamic variables, sending a complete structured instruction to the LLM (e.g., OpenAI GPT) for real-time, emotionally intelligent replies. With all components working in sync, SoulSense will become a truly adaptive, context-aware, and deeply human-like AI companion—capable of offering not only conversation, but comfort.
