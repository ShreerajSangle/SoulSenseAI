💡 5. Context-Aware Features (Goal, Journal, Quick Replies)
Your chat engine should auto-inject:

Goal creation flow (detect phrases like “I want to improve” and guide user)

All of these are part of your controller layer — not Claude. Claude just replies. Your app handles logic.

✨ 6. Avoiding Repetition
Claude sometimes repeats if:

The system prompt is too rigid.

Message history isn’t well tracked.

Solution:

Keep last 5–10 message turns in every call.

Use Claude’s built-in capabilities by clearly telling it:

"Avoid repeating yourself. Keep responses varied and emotionally fresh like a real human."
