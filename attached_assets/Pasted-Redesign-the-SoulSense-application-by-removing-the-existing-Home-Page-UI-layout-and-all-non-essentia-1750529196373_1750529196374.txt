Redesign the SoulSense application by removing the existing Home Page UI layout and all non-essential homepage elements that currently clutter the user experience. Instead of showcasing static cards, quotes, or unnecessary dashboard components on the home screen, the user should be immediately directed into a seamless, full-screen persona-based conversation interface upon launching the app. This conversation interface should be the heart of the system — allowing users to directly engage with their selected persona (Dr. Sarah, Marcus, Maya, or Alex) in a rich, immersive dialogue powered by OpenAI’s GPT-4o model. The interface must enable emotion-aware response generation, where the chatbot understands the user's emotional tone in each input and tailors its replies accordingly. Each conversation should feel natural, supportive, and uniquely suited to the selected persona’s character and therapeutic style. For example, Sarah should respond with empathy and clinical reassurance, while Alex might use humor and casual tone.

The interface should support real-time typing animations, token streaming, and soft transitions for every message, making conversations more human and engaging. The focus should be on emotionally intelligent, contextually aware conversations, with background emotion detection using models like GoEmotions running silently in the backend to detect and pass emotional cues to the GPT-4o prompt. This will allow the AI to dynamically adjust tone, style, and suggestions (e.g., breathing techniques, affirmations, gentle probing questions) without overwhelming the user with a robotic or repetitive experience. All elements such as session summaries, mood tracking, and prompts can be integrated subtly within the chat flow itself — no need for a separate homepage or dashboard view. The goal is to make the chat experience the primary and only entry point into the SoulSense journey, ensuring deep emotional engagement, persona consistency, and intelligent support from the very first message.
