Design the SoulSense user interface to embody a soothing, emotionally engaging experience by using a calming and cohesive aesthetic based on a lavender color palette. The overall visual tone should feel soft, supportive, and welcoming—something users want to return to daily. The primary background should be a gentle lavender shade (#E6E6FA), complemented by gradient accents fading into dusky rose or pastel pinks to add depth and warmth. All interactive components—such as cards, chat bubbles, and input fields—should use rounded corners, light shadows, and subtle glassmorphism to evoke softness and comfort. Text should appear in deep gray or muted plum tones to maintain readability without harsh contrast.

The homepage and the persona chat interface should feel seamlessly unified within a single-page layout, avoiding jarring transitions or context shifts. When a user selects a persona, the chat interface should elegantly overlay the existing dashboard, preserving the gradient background and main structure. The persona’s avatar, name (e.g., “Dr. Sarah”), and title should be cleanly displayed at the top, accompanied by a warm welcome message and subtle animated emotion indicators like “Emotion: Calm 😊 | Intensity: 40%.” The chat input area should be minimalist—featuring only a text box, emoji icon, and send button—with no microphone or voice features to keep the space distraction-free.

The entire UI should feel responsive and fluid, with gentle animations such as floating send buttons, pulsing typing indicators, and fade-in messages to enhance interactivity. Light motion in the background or soft particles can be added to reinforce a calming ambiance without overstimulating the user. A dark mode option can be introduced using soft lilac and plum tones to preserve the tranquil atmosphere at night. Every design choice should prioritize emotional safety, privacy, and an intuitive, calming interaction flow. Ultimately, SoulSense should feel like a digital sanctuary—visually elegant, emotionally intelligent, and deeply user-friendly.
